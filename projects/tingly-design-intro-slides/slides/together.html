One setting puts every design request behind your box

Quick AI uses the Anthropic SDK and delegation runs Claude Code. Both read ANTHROPIC_BASE_URL, so there is no integration to install.

# before pnpm dev

export ANTHROPIC_BASE_URL=http://localhost:12580/tingly/anthropic

export ANTHROPIC_API_KEY=<your Tingly Box token>

pnpm dev
