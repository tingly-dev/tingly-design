The Import / Export list per kind is in .design/export-menu.md. Every kind lists Copy as PNG right after its PNG image: the same picture on the clipboard, or downloaded when the browser cannot. Canvas, slides, design system and dashboard add Claude Design package (.zip) just before the two whole-project items; docs and motion do not (.design/claude-design-format.md). AI model settings is the only place a model is chosen (.design/ai-settings.md); new model features join it rather than adding a dialog. It is three cards, top to bottom, one per job, and each carries its own connection (nothing is shared or linked between them): (1) Claude Code, with tabs for how it runs (its own local sign-in with no fields, Tingly Box with a token, an optional profile and the address claude is given, or a custom address with key and model); (2) ImageGen (Tingly Box’s image address or another one, its own token or key and model, and a switch that keeps the settings; each project has its own switch, default on, in the request bar); (3) Fast AI (Tingly Box, Anthropic or another address, key, model and a Test). Each card’s header says what it still needs. A Tingly Box card with no token can take another Tingly Box card’s at save (“Use the token from Claude Code”): a copy, not a link. The dialog scrolls in the viewport, title and buttons in place. ↺ opens the change history (journal and undo), described in .design/server-log.md; its Commit to git opens a dialog that says which repository and branch the commit lands on, or that a repository will be created in the project folder (.design/project-git.md).

Deleting

Removing a slide, scene, tab, artboard or comment thread is not asked about: it is done, and the toast carries Undo for a few seconds. Only what cannot be brought back (a design system’s image or font file) asks first, in the editor’s own dialog.
