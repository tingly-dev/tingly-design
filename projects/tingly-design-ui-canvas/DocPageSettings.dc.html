▸ Design systems
3
Width sits next to the page. The formatting bar keeps block tools left and page width right, after a rule; it shows the current value and needs no second top-bar icon.
4
Faces live with the look. The own look defines them; a worn theme shows its faces read-only with the way back, so nothing is dead.
5
“Standard” says whose column. 677 px by default, the worn theme’s column when it gives one; the width menu shows it.
Why this shape
Theme is a project-level look and keeps its top-bar place. Page width is a property of the page being edited, so it belongs beside the page’s own tools; the formatting bar already wraps and has room at its right end. Faces are what a theme already promises, so Theme owns them and the second popover disappears.
What changed
The top bar keeps Theme and drops Layout. Page width is a value dropdown at the right end of the formatting bar. Theme’s cards own the faces: the own look’s two choices, or a worn theme’s own, read-only.
Open
Canvas and slides keep their Theme in the inspector and have no page-width control. A theme that supplies only one face leaves the other row editable. The width control wraps below about 700 px.
