Theme
A top-bar button (a doc has no right panel): the same word and the same cards as the canvas’s and deck’s Theme tab. Lit while a system is worn.
2
The doc’s look
The first card. No design system: what the editor has always drawn. One click, one undo step; no preview state.
3
One card per installed theme
Drawn in the theme’s own page colour, text, brand colour and face. WeChat is a built-in look (group Platforms); Nord has a dark theme, so the page goes dark and the text colour names (red, green…) take values made for a dark page.
4
The page
Only the doc’s page wears the theme; the editor’s chrome, menus and the comment rail keep the editor’s own theme. The files stay Markdown: doc.json keeps only designSystems and theme.
5
Which one
One line: what the doc wears now. The WeChat article, HTML, PDF and PNG read the same values (Word does not yet).
6
Design systems
Installing wears it at once; removing the worn one puts the doc back to its own look. Folded when a system is installed, open when none is.
