1
Top bar
Word count, layout (page width), Import / Export, Comments with an unread count.
2
Tabs
One Markdown file each; nest by indenting; “+ Tab” at the end.
3
Outline
Headings of the open tab.
4
Format bar
Undo / redo, block style, inline marks, lists, quote, table, picture, divider. Belongs to the document, not the project, so it stays out of the top bar.
5
Page
One tab on a sheet. Commented passages are highlighted. Selecting words opens a small bar above them: bold, italic, strike, code, highlight, text colour (six named colours, then a clear button), link, comment, ask Claude.
6
Comments
Threads pinned to passages; reply and resolve here.
7
Agent bar
Whole doc or the selected passage.
