Canvas template values

The values an artboard exposes through data-props, for the whole canvas at once. They sit in the right panel when nothing is selected, and an artboard’s Tweaks ends with a link to them. When artboards share a value name, By name lists it once with a Set all (one undo step). See .design/canvas-template-values.md.

1
Template values
Under Canvas when nothing is selected; from a selected artboard’s Tweaks the link at its end (C) comes back here. One group per artboard, in canvas order; artboards that declare no values do not appear.
2
Same fields as Tweaks
Text, colour, toggle, number: the same controls and the same write-back. An edit changes that artboard’s default, can be undone and shows in the change log.
3
Group header
Click it to select the artboard and bring it into view; the panel then shows that artboard’s own Properties and Tweaks. The arrow folds the group.
4
Filter
Past 30 values a name filter appears at the top of the section; below that it is left out.
5
Empty state
Teaches the one line that declares a value, so the section is never a blank box.
6
Canvas only
Slides and motion set an embedded artboard’s values on the embed (already in Properties); other kinds have no template values.
Open
Same-name values: Set all is explicit and never automatic; should a name that is always equal become a design-system token? Values that scripts read but data-props does not declare: not listed.
