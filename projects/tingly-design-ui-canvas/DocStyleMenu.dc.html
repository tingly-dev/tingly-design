4
One button, one question. “How does this doc look?” opens everything; no second page-level icon in a top bar that does not fold below 900 px.
5
A dead control becomes an explanation. A theme that gives faces shows them read-only with the way back; the doc’s own look keeps the two toggles.
6
Concrete values. Standard says whose column it is and how wide; no alias with two meanings.
Why this is odd today
The two popovers overlap on faces and on the page measure; the doc’s “own look” is chosen in Theme but defined in Layout. “Layout” also means flex / grid in the canvas, slides and motion inspector (both are Layout in English), and the icon promises columns the menu does not have.
Options weighed
A · merge (drawn) — one Doc style popover, grouped; fixes ownership and dead controls; taller popover, more code. B · keep two, rename and explain — smallest change; still two peer buttons and a split own look. C · split by axis — Theme owns faces, a “Page” menu owns width; cleanest axes, still two buttons and a new “follow the theme column” decision.
