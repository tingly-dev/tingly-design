# 数学奇遇记 视觉系统

《数学奇遇记》是一组讲“会动的数学瞬间”的幻灯片：每一页一个反直觉的结论，右边一段动画把它演出来。这个系统从那套幻灯片（`projects/math-deck`）里提取：颜色、字号、卡片都是那 8 页实际用的值。

## 语气

- 先提问，再给答案：标题是现象（“绕地球的绳子”），说明文字是一个让人猜的问题，答案放在卡片里。
- 短句，口语，允许一个“啊？”。不用感叹号堆砌，不用“颠覆认知”这类词。
- 数字要准：写“≈ 16 厘米”，不写“很小的缝”。

## 视觉基础

- **夜空背景**：每页是 `night-raised` → `night` 的径向渐变，圆心偏右（动画在右边）。不用纯黑。
- **两种字体**：标题用 ZCOOL QingKe HuangYou（`display`，只有 400 一种字重），其余用 Noto Sans SC（`sans`）。
- **字号阶梯**：128 / 80 / 64 / 30 / 24 px，不加别的字号；最小 24px。
- **强调色**：`cyan` 管眉题和卡片描边，`gold` 只给答案数字，`pink` 只出现在渐变和动画里，`orange` 只在动画里。
- **卡片**：`card-fill` 底、1px `card-line` 描边、`radius-card` 圆角，内边距 28px × `space-card-x`。一页最多一张卡片，放答案。

## 用法规则

| 要做的 | 用 |
|---|---|
| 页标题 | `slide-title`，颜色 `ink` |
| 标题上方的“EP.0x · 主题” | `eyebrow`，颜色 `cyan` |
| 提问的那段话 | `lead`，颜色 `ink-muted`，宽 520–620px |
| 答案 | 卡片里的 `stat`，颜色 `gold`，下面一行 `body` / `ink-muted` |
| 页脚 | `body`，颜色 `ink-faint`，钉在 bottom 64px |

文字对比度：`ink`、`ink-muted`、`cyan`、`gold` 在 `night` 和 `night-raised` 上都在 4.5:1 以上；`ink-faint` 只用于 24px 的页脚。
