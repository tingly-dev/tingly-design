New project
Pick a kind, then optional first choices. Starter pages are plain and light. Change folder takes a name (projects/…) or a full path. The menu ends with Import HTML or SVG…, Import PowerPoint (.pptx)…, Import Markdown (.md)…, Import a project package (.zip)… and Open a folder…. Each file action opens its own filtered picker directly; ZIP accepts Tingly Design and Claude Design packages. Dropping a PPTX still opens the same conversion flow. Open a folder says what is at a path while it is typed. A card’s ⋯ also offers Export (.zip).
