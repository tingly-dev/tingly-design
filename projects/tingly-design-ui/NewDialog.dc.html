1
Kind. The same row for every kind; Canvas is preselected from New project, or the current project’s kind.
2
Title. Optional; the folder follows it.
3
Size. Canvas only (Motion has its own row of formats). Categories (Screen, Slides, Social and covers, Web ads, Print, Custom) are listed on the left; the picked one shows only its own sizes on the right. The sizes come from one list, BOARD_SIZES in @dc/core, also used by the board panel’s preset menu and by tingly-design new canvas --size. Each shows its real width × height; “Custom” opens two number fields (1–7680 px). The right side scrolls inside a fixed height when a category has more sizes than fit, so Create stays in view. Artboard 1200×760 is picked first.
4
Where it is used. One line for the picked size (hover shows it for the others), so a WeChat cover is findable without knowing 900×383.
5
Start with. Design system and, for Dashboard, a data file; the size is no longer here.
