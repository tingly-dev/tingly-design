Kind. The same row for every kind; Canvas is preselected from New project, or the current project’s kind.
2
Title. Optional; the folder follows it.
3
Size. Shared by Canvas, Slides and Motion. Categories (Screen, Slides, Social and covers, Web ads, Print, Aspect ratios, Custom) are listed on the left; the picked one shows only its own sizes on the right. The sizes come from one list, BOARD_SIZES in @dc/core, also used by the board panel’s preset menu and by tingly-design new canvas --size. Each shows its real width × height; “Custom” opens two number fields (1–7680 px). The right side scrolls inside a fixed height when a category has more sizes than fit, so Create stays in view. Canvas starts at Artboard 1200×760; Slides at Wide 1920×1080; Motion at its last size, or Wide 1920×1080. Motion also lists Your sizes for saved custom dimensions. The Aspect ratios group adds 3:2, 2:3, 2:1, 1:2, 21:9, 2.39:1 and 16:10.
4
Where it is used. One line for the picked size (hover shows it for the others), so a WeChat cover is findable without knowing 900×383.
5
Start with. Design system and, for Dashboard, a data file. The system field lists your projects; Built-in stays collapsed underneath. Expand it to browse one look group at a time; picking one shows its original English name in the field and closes the group. Canvas and Slides install it directly, with no extra design-system project.
Open Which sizes belong in the list is a product call (presets are data, one line each). All three use the same picker. A deck keeps its chosen size in deck.json; the stage, thumbnails, presentation and exports agree. Older decks default to 1920×1080. The command line has its own interactive prompt.

7
Start from a look. Design system only. Blank (the first group, picked first) is the small neutral starter; the other groups (Clean and light, Editorial, Bold and playful, Technical, Editor palettes) list the looks that feel alike, 36 in all, from one list, LOOKS in @dc/core, also used by tingly-design new design-system --look. A swatch shows each look in its own page colour, ink, accent and type. A look sets the colours (one theme), font families, radii and shadows; text styles and spacing stay generic, and the README keeps the look’s MIT credit.
Open The look is a start, not a link: once created the system is the person’s to edit. A DESIGN.md or tokens.css import (bring your own) is not here yet.
