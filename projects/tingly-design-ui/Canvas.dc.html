Top bar
Play, Import / Export, the right panel toggle; then ⋯. See “Top bar anatomy”.
2
Tool bar
Page picker and drawing tools only. It floats because tools belong next to the work.
3
Zoom
Its own small float, top right of the board.
4
Artboards
Each is a file (*.dc.html). Title above; focus and save as PNG on hover. Notes and pictures sit between them.
5
Right panel
Properties: the layer tree (eye and lock on every row; Shift or ⌘-click ticks several rows, a bar under the tree hides or locks them together, Alt-click an eye keeps only that one), then the selected element’s size, layout and text. A locked layer’s fields are read-only, under a notice with an Unlock button. Code shows the file; Tweaks the artboard’s levers. With nothing selected: the canvas, then every artboard’s template values (see “Canvas template values”).
6
Agent bar
What it will change (a chip), new or continued conversation, Fast AI or Claude Code.
Open
Artboard size: a preset or W/H also rescales the page inside (“Scale the page with the size”, on by default); when the shape changes a lot the panel offers “Ask Claude to re-lay out”. Selecting several layers on the stage itself (marquee, Shift-click) does not exist yet; ticking rows lives in the tree only. Pages: the picker lives in the tool bar, but a page is a project-level thing. Move it to the top bar, or keep it beside the tools?
