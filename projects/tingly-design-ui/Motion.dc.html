1
Top bar
The name (double-click to rename, as in every kind), then size (one segment per format), speed, notes, check, Import / Export, the right panel toggle. While a video exports, a fixed-size readout (“Exporting 42% · 21 fps · 33 s left”, tabular digits, a tinted bar filling left to right, click to cancel) sits before Import / Export; it never changes size, so the bar around it stays still.
2
Stage
The frame at the playhead, at the chosen size. Paused, it is editable like a slide.
3
Timeline
Play, time, “+ Scene”, then one block per scene sized by its length (right-click a block: add after, duplicate, move earlier / later, delete); the cover is the poster before 0, or a pin on the ruler for a frame of the video (drag it; “Use as cover” sets it at the playhead).
4
Right panel
Properties (tree, name, frame rate, sizes) and Code. “Add size” starts the new format from the primary layout rescaled (its own data-<format> overrides) and offers “Ask Claude to re-lay out” when the shape changes a lot; it opens the same size picker as the New dialog (categories, then sizes, or Custom); the format takes the size’s name. Every size but the main one has a ×: it asks only when scenes hold overrides that belong to it, then a toast “Deleted size tall. Undo” brings everything back at once; the main size has no × (its tooltip says why) because the layouts are written for it. Claude Code is told the size was removed. “Your sizes” (custom sizes typed in a picker) is the same group in Canvas, Slides and Motion, each with its own ×.
5
Agent bar
Targets the scene or the selected element.
