# Marks

- `tingly-mark.svg` — the mark: a white T in a rounded ink square, as in the Tingly Box app and favicon. On dark backgrounds, invert it: a `#eceef2` square with an ink T. Keep clear space of a quarter of its width.
- `tingly-wordmark.svg` — the mark with the name set in Inter Semibold. Use it where the product name is not already on screen.
