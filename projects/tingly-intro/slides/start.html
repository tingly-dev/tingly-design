GET STARTED

Two commands to try both

THE GATEWAY

Tingly Box

npx tingly-box@latest

Starts the gateway on port 12580 and opens the web UI. npm and Docker installs are in the README.

github.com/tingly-dev/tingly-box

THE WORKSPACE

Tingly Design

pnpm install && pnpm dev

Opens the editor at localhost:5173 with five sample projects, this deck among them.

github.com/tingly-dev/tingly-design
