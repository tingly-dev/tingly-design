# Marks

- `meridian-mark.svg` — the mark: a globe outline with one meridian in brand. Ink `#14171f` on light surfaces; on night, swap the outline to `#f3f4f6`. Keep clear space of half its width.
- `meridian-wordmark.svg` — the mark with the name set in Inter Semibold. Use it where the product name is not already on screen.
