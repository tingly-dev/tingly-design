# 幻灯片的 deck 级检查

状态：已实施（`check` / `check --snapshots`，命令行与 MCP）；编辑器内把这些结果交给 Claude Code 见 #502 的方案。

## 问题

`check --snapshots` 原来逐页看：文字被裁、出界、对比度低、什么也没画、盒子溢出、文字被挤。生成的 deck 最常显得“没做完”的几种毛病不在其中：要么在页与页之间（同类页的标题一页高一页低），要么没有量（留在页面上的 `[€__]`、明显过小的字、单词被拆成两行、“26”在行尾而“M”在下一行、内容页只占上半页）。这些都是 slides 技能里写着的规则，pptx 技能的看图清单也逐条列出（[research-pptx-skill.md](./research-pptx-skill.md)）；agent 看图时倾向于放过程度问题，所以要让检查把它们说出来。

## 决定

**两处来源，一种说法。** 能从文件读出来的在 core 里读，要看排出来的样子的在版面探针里量；都只给规则 id 和数值，措辞在 `cli.layoutRules` / `cli.slidesRules`（英中）。

| 规则 | 在哪里判 | 什么时候报 | 为什么这样定 |
|---|---|---|---|
| `placeholder`（`slides`） | core `deckCheck.ts` 的 `slidePlaceholders`，`check` 不画图也报 | 页面可见文字里有方括号填空（`[€__]`、`[Name]`、`[insert logo]`、全大写的 `[COMPANY NAME]`），或 `lorem ipsum`、`TODO`、`TBD`、`XXX` | 技能让 agent 在缺数据时写方括号占位并在回复里列出；交付前它们应被填掉或被人看见。`[[维基链接]]`、`[1]` 这种引用、普通的方括号词不算；备注、隐藏元素、SVG 和嵌入块里的不算 |
| `small`（`layout`） | 版面探针，幻灯片才跑 | 有字的元素的计算字号低于下限的 90%；下限是短边 1080 时的 24px，按 deck 尺寸等比 | 下限是技能的规则；留 10% 是因为小号大写加字距的眉题常写 22px，这是选择，明显更小才是错（示例 deck 正是 22px 眉题） |
| `broken`（`layout`） | 版面探针 | 拉丁、希腊、西里尔字母或数字的单词中间换了行，且断处不是连字符 | 中日文本来就可以在任意字间换行，只看用空格分词的文字 |
| `unitSplit`（`layout`） | 版面探针 | 行尾是数字、下一行开头是它的单位（`%`、`M`、`bn`、`ms`、`€`…），或行尾是货币符号、下一行是数字 | 读的人会把“M”当成新的一句；修法是放宽框或用不换行空格 |
| `short`（`layout`） | 版面探针 | 第一个 `h1`/`h2` 在页面上部 30% 内、下面还有内容，而内容（文字、图片、表格、形状、嵌入块，含 pinned 的；不含页脚带和铺满整页的背景）在页面高度 62% 之前就结束了 | 技能的 craft 页写着“内容页的内容停在 60% 高度处读起来像没做完”；62% 给这个说法留一点余量。对比实验里 66–70% 的页看着也偏空，但示例 deck 的两页在 64%、68%，人看是安静的版式，不是错，所以不往上提 |
| `headingMoved`（`slides`） | 版面探针给每页的第一个 `h1`/`h2` 记一条 `heading`（标签、字号、上和左），`commands.ts` 交给 core 的 `slideHeadingDrift` 跨页比 | 标签和字号相同、位于上部三分之一的标题至少三页成组，取上、左的中位数为“惯常位置”，偏离超过 6px 的报出，带偏了多少和几页在惯常位置 | 两页时分不出谁错；居中的陈述页、封面不在上部三分之一或字号不同，不参与比较。`heading` 记录本身不是警告，不出现在结果里 |

**都是警告。** 有意留下的占位、故意压小的注释、只放一句话的页都可能是设计，检查分不出来。

**只对幻灯片。** 规则放在探针的 `slide` 参数后面，由 `KIND_CLI` 的 `deck` 一栏决定（只有 slides 为真），画布板子、看板、文档不受影响。探针里幻灯片这一段包在 `try` 里：它出错不会让同一框架里前面的规则结果一起丢掉。

## 验证

core 单测（`deckCheck.test.ts`）覆盖占位与不该报的方括号、看不见的文字、`check` 的输出形状，以及标题漂移的成组、三页门槛和横向偏移；`pnpm e2e check_snapshots` 在一份带问题的示例 deck 副本上逐条断言，并断言示例 deck 本身没有 deck 级警告。
