# 设计系统一眼看懂：概览页和启动页卡片

状态：**已实施**。核心是 `packages/core/src/designSystem.ts` 的 `dsGlance`，画面是 `apps/editor/src/components/ds/Specimen.tsx`。

## 1. 要解决的问题

两套设计系统的启动页卡片都是一排色块、一个字体名、几个组件名，看上去几乎一样；打开后的概览页只有封面和 README，要读完文字才知道它是什么、和另一套差在哪。用户在两个地方问的是同一个问题：**这套系统长什么样，和那套有什么不同**。

## 2. 决定

| 问题 | 决定 | 为什么 |
|---|---|---|
| 怎么让差别一眼可见 | 一张"样张"：用这套系统自己的页面色、卡片色、文字色、品牌色、标题字体和正文字体、圆角、阴影画一张小卡片（标题、一句正文、按钮、`Aa`） | 差别在于组合，不在单个色块；颜色、字体、形状同时变，样张才看得出是两套 |
| 多个主题 | 样张并排画前两个主题（如浅色 | 深色），各自带主题名 | 浅色和深色是同一套系统最容易被误认成两套的地方；并排才看得出角色对应 |
| 角色从哪取 | `dsGlance` 按品牌手册常用的名字取（`paper`/`background`、`surface`/`card`、`ink`/`text`、`brand`/`primary`/`accent`），取不到就用饱和度最高的颜色当品牌色，没有的角色用中性回退色 | 不要求用户改名；token 名不同的系统也能出样张 |
| 字体 | 标题取 `display`/`heading` 族或名字像标题的文字组，正文取 `sans`/`body` 族，再回退到声明顺序 | 同上 |
| 启动页卡片 | 样张铺满预览框（框里不再套框）+ 底边一条细色带（先放页面、卡片、文字、品牌四个角色，再放其余）+ 用各自字体写的字体名；数量已经在卡片的元信息里，不再重复；不列组件名 | 组件名在卡片上没有区分度；数量能看出一套系统有多完整 |
| 概览页 | 顶部"一眼"区：样张、一句话说明设计系统是什么、字体 / 形状 / 主题三行、四个数量，下面是带 token 名的完整色板，再是封面和品牌手册 | 先回答"这是什么、什么样"，再给细节；说明放在产品里，不让用户去读文档 |
| 样张放哪 | 启动页和概览页共用同一个 `Specimen`；数据都来自 `dsGlance`（启动页经 `ProjectPreview` 带过去） | 两处说的必须是同一件事；不在前端再读一遍 tokens |
| 取舍 | 样张是示意，不是组件预览；具体组件仍在"组件"页 | 样张要小而稳定，不跑沙箱，卡片列表才不会变慢 |

## 3. 还开着的问题

- 启动页会为样张加载托管字体（Google Fonts 样式表），离线时回退到系统字体。
- 样张最多并排两个主题；三个以上的系统只画前两个。
- 角色识别靠名字；以后可以让 `tokens.json` 里直接标出角色，名字取不到时才猜。
