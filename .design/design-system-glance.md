# 设计系统一眼看懂：概览页和启动页卡片

状态：**已实施**。核心是 `packages/core/src/designSystem.ts` 的 `dsGlance`，画面是 `apps/editor/src/components/ds/Specimen.tsx`；启动页卡片有封面时画封面（`launcher/Preview.tsx` 的 `CoverFrame`，数据由 `projectCard` 带上）。

## 1. 要解决的问题

两套设计系统的启动页卡片都是一排色块、一个字体名、几个组件名，看上去几乎一样；打开后的概览页只有封面和 README，要读完文字才知道它是什么、和另一套差在哪。用户在两个地方问的是同一个问题：**这套系统长什么样，和那套有什么不同**。

## 2. 决定

| 问题 | 决定 | 为什么 |
|---|---|---|
| 怎么让差别一眼可见 | 一张"样张"：用这套系统自己的页面色、卡片色、文字色、品牌色、标题字体和正文字体、圆角、阴影画一张小卡片（标题、一句正文、按钮、`Aa`） | 差别在于组合，不在单个色块；颜色、字体、形状同时变，样张才看得出是两套 |
| 多个主题 | 样张并排画前两个主题（如浅色 | 深色），各自带主题名 | 浅色和深色是同一套系统最容易被误认成两套的地方；并排才看得出角色对应 |
| 角色从哪取 | `dsGlance` 按品牌手册常用的名字取（`paper`/`background`、`surface`/`card`、`ink`/`text`、`brand`/`primary`/`accent`），取不到就用饱和度最高的颜色当品牌色，没有的角色用中性回退色 | 不要求用户改名；token 名不同的系统也能出样张 |
| 页面色叫 `surface` 的系统 | 没有 `paper`/`background` 一类名字时，`surface` 就是页面色，卡片取 `surface-raised`/`card`/`panel` | 新建起点和所有风格都这样命名；否则样张的页面会退回中性灰，卡片却用了页面色 |
| 卡片的边和阴影 | 用系统自己的 `line` 颜色画 1px 边，用第一个阴影 token 的真实值（`var(--颜色)` 代入） | 包豪斯的硬投影、赛博朋克的霓虹光、瑞士网格的细线都靠这两样认出来；统一的柔和阴影会把它们抹平 |
| 字体 | 标题取 `display`/`heading` 族或名字像标题的文字组，正文取 `sans`/`body` 族，再回退到声明顺序 | 同上 |
| 启动页卡片画什么 | 系统有封面（`components/Cover/preview.html`）时画封面：和概览一样先加载 `tokens.css` 再加载 `components/bundle.css`，用第一个主题，按卡片比例选一个排版宽度（720–1440 px）再缩小铺满；没有封面时画样张 | 样张只有 tokens，描边粗细、渐变字、发光、网格线、侧边条这些风格的一半在组件样式里，卡片上看不出来，而启动页正是挑项目的地方。封面是系统作者自己选的门面，幻灯片和动效的卡片也是画封面，三种说同一件事。卡片上不加载 `bundle.js` 和组件库，列表里几十张卡片也不慢；封面里自己的脚本照常跑 |
| 启动页卡片的布局 | 预览（封面或样张）铺满预览框（框里不再套框）+ 底栏一行：左边用各自字体写的字体名，右边几个小圆点色样（先放页面、卡片、文字、品牌四个角色，再放其余），不贴着样张边缘也不占块面；数量已经在卡片的元信息里，不再重复；不列组件名 | 组件名在卡片上没有区分度；数量能看出一套系统有多完整 |
| 概览页 | 顶部"一眼"区：样张、一句话说明设计系统是什么、字体 / 形状 / 主题三行、四个数量，下面是带 token 名的完整色板，再是封面和品牌手册 | 先回答"这是什么、什么样"，再给细节；说明放在产品里，不让用户去读文档 |
| 样张放哪 | 启动页和概览页共用同一个 `Specimen`；数据都来自 `dsGlance`（启动页经 `ProjectPreview` 带过去） | 两处说的必须是同一件事；不在前端再读一遍 tokens |
| 概览页的样张 | 仍是 tokens 画的样张，不换成封面 | 概览里封面就在下面、原尺寸；样张在这里的用处是把前两个主题并排对照，封面一次只画当前主题 |
| 第二个品牌色和字号阶梯 | 样张不加 | 有封面的系统，封面已经画出全部品牌色和字号；没有封面的系统，完整色板和"字体"页就在概览里。样张再加会变挤，也不再是"一眼" |
| 取舍 | 样张是示意，不是组件预览；具体组件仍在"组件"页 | 样张要小而稳定，不跑沙箱 |

## 3. 还开着的问题

- 启动页会为样张加载托管字体（Google Fonts 样式表），离线时回退到系统字体。
- 样张最多并排两个主题；三个以上的系统只画前两个。启动页的封面只画第一个主题。
- 封面若靠 `bundle.js` 里的组件或外部库才画得出来，卡片上会缺这部分；目前的封面（风格起点、示例系统、从 Claude Design 导入的）都是纯 HTML 和 CSS。
- 角色识别靠名字；以后可以让 `tokens.json` 里直接标出角色，名字取不到时才猜。
