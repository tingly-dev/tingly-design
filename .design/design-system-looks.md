# 设计系统的起点：风格（looks）

状态：**已实施**（颜色、字体、圆角、阴影）；组件、DESIGN.md / tokens.css 导入是**方案**，见 §4。调研在 `.research/opendesign.md` 第 3 部分。

## 1. 要解决的问题

新建设计系统只有一个小的中性起点，用户要从空白开始自己填颜色、字体和圆角。OpenDesign 有 151 个品牌设计系统和 html-ppt 的 36 个主题，用户一上来就能挑一个"感觉对"的再改。我们要的是同样的"更快用起来"，但不照搬它的整套库。

## 2. 决定

| 问题 | 决定 | 为什么 |
|---|---|---|
| 拿什么 | 只拿 html-ppt 的 36 个 CSS 主题（MIT，© 2026 lewis） | 它们是统一的 `:root` 变量，几乎就是 `tokens.json`；许可明确。151 个品牌包是第三方品牌的描述，授权和商标没核实，不内置 |
| 怎么进来 | `scripts/import-looks.mjs` 从主题文件生成 `packages/core/src/looks.data.ts`（只存数值），`looks.ts` 把它变成 `tokens.json` | 不搬它的代码；重新生成就能跟上游 |
| 一个风格带什么 | 颜色（一套主题，亮或暗）、字体族和要托管的字体、圆角、阴影；文字样式和间距用通用的 | 原主题只有这些；文字大小和间距没有"风格"可言 |
| 阴影里的颜色 | 原主题的 `var(--accent)` 换成我们的颜色名 | `shadow` 允许 `var(--颜色名)`，阴影跟着主题走 |
| 分组 | 干净明亮、编辑出版、大胆活泼、科技感、编辑器配色，各风格只属于一组（`import-looks.mjs` 里的 `GROUPS`） | 36 个平铺没法挑；按"感觉"分，用户问的是"我要什么感觉" |
| 在哪里选 | 新建对话框选"设计系统"后出现"从一个风格开始"：左边是分组（空白在最前，默认），右边是该组的风格，每个用自己的页面色、文字色、强调色和字体画一个小样；命令行 `new design-system --look <id>`，MCP `open` 的 `look` | 和新建画布选尺寸是同一种交互；空白是默认，不多问一步 |
| 名字 | 每个风格和分组的中英文名在 `ds.look.<id>` / `ds.lookGroup.<group>`，测试查不能缺、不能多 | 同 `boardSizes` |
| 许可 | 生成的 README 写明来源和 MIT 版权行 | MIT 要求保留 |
| 之后 | 建好就是用户自己的系统，不保留和原风格的链接 | 风格是起点；要换风格就新建 |

## 3. 取舍

- 不另存一份"风格"文件夹：36 个风格以数据形式在核心里，不增加 36 个示例项目。
- 数值取自原主题，但原版只有一张演示页，没有组件设计，所以起点是"颜色和字体"，不是"一套成品"。

## 4. 还开着的问题

- **组件**：给风格补一组通用组件（按钮、卡片、标签、输入框……），用风格的变量画。作为单独的一步。
- **导入 DESIGN.md / tokens.css**：用户自己带来的文件转成 `tokens.json`，说明文字进 README；不内置品牌包。
- 风格的名字目前直接沿用原主题名；`catppuccin`、`dracula` 等编辑器配色是别人的配色方案，名字只用于标明出处。
