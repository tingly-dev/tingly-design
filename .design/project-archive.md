# 整个项目导出成一个 .zip，再从首页导入

状态：**已实施**（导出菜单、启动页导入和导出、命令行、服务端打包和解包）；§6 是没做的。

## 1. 问题

导入 / 导出菜单里的导出项都是成品：图片、PDF、HTML、视频。想把项目交给别人、换一台机器、或者留一份备份的人，要的是项目本身（源文件、`uploads/`、`data/`、字体、装进来的设计系统），而这个入口没有。项目文件夹虽然就在磁盘上，可是用户不一定知道它在哪；就算知道，自己打包也会把 `.git`、渲染好的视频、本机的运行记录一起带走，或者漏掉它用到的设计系统。

## 2. 决定

- **一个 .zip，里面是并排的项目文件夹**：`<项目>/` 是项目本身，带上设计系统时，`<系统>/` 和它并排；顶上一个 `tingly-design.json` 说明哪个文件夹是项目、是什么类型、带了哪些系统、有没有改动记录。解开后每个文件夹都能直接用"打开文件夹"打开，不依赖导入功能。
- **默认什么都带，另有一项“仅文件”**：用户的答复是“可以带上，或者有选项”。菜单里的两项就是这两种：整个项目（所有文件、改动记录、用到的设计系统），以及仅项目文件（不含改动记录和设计系统）。没做成带复选框的对话框：只有两种组合有用，两行菜单就说清了，不多一步。
- **六种类型一样**：两项放在共用的 `FileMenu` 里，排在每种类型自己的导出项后面，用分隔线隔开。不需要每个类型各自接入。启动页项目卡片的"⋯"菜单里也有一项"导出（.zip）"（整个项目），不必先打开项目。
- **导入在启动页的"新建"菜单里**，和"导入 HTML 或 SVG""打开文件夹"放在一起：都是“从外面带进一个项目”。导入后直接打开这个项目。

## 3. 带什么、不带什么

| 内容 | 整个项目 | 仅文件 | 为什么 |
|---|---|---|---|
| 项目文件、`uploads/`、`data/`、`ds/`（装进来的 tokens 和字体）、`fonts/`、`assets/` | 带 | 带 | 项目本身 |
| `.journal.jsonl`（改动记录） | 带 | 不带 | 有了它，改动记录和撤销在新机器上也接得上；交给别人时可能不想带 |
| 用到的设计系统（画布、幻灯片 `designSystems` 里 `artifact: projects/<名字>` 指向的项目） | 作为并排的项目带上 | 不带 | 装进项目的只是 tokens 和字体的副本（够画），组件、说明、样张在系统自己的项目里；拿到的人要重新装或改系统时需要它 |
| `.git/`、`renders/`、`.runs.json`、`.claude-session.json`、`.transcript.jsonl`（对话记录）、`node_modules/`、其他点文件 | 不带 | 不带 | 属于这台机器（和 [project-git.md](./project-git.md) 不提交的那些一致） |

## 4. 导入

- 读法：有 `tingly-design.json` 就按它；没有（手工打包的）时，压缩包顶层就是一个项目，或者顶层每个文件夹是一个项目，第一个不是设计系统的那个是主项目。所以直接把项目文件夹压成 zip 也能导入。
- 名字：导入成项目文件夹里的新项目，名字取原来的文件夹名（或压缩包文件名），重名时加 `-2`、`-3`。标题不变。
- 设计系统：同名的系统已经在、而且 `tokens.json` 一样时，不再导入一份，项目直接用已有的那个；否则作为新项目导入，名字变了的话，把主项目索引里 `designSystems[].artifact` 改到新名字。
- 安全：拒绝 `..`、绝对路径；解开后超过 1 GB 或 2 万个文件就停（防压缩炸弹）；先写进项目文件夹里的一个隐藏临时文件夹，写完再整个改名到位，半途失败不留下半个项目。忽略 macOS 打包时加的 `__MACOSX/`。

## 5. 放在哪里

- 规则（带什么、怎么读压缩包、取名）在 core 的 `projectArchive.ts`，没有文件系统，单元测试覆盖。
- 服务端 `archive.ts` 读写文件夹，用 fflate（纯 JS，打包进 bundle，不需要本机工具）。接口：`GET /api/projects/:p/archive`（`?journal=0&systems=0` 是仅文件），`POST /api/archive?file=<文件名>`（请求体是 zip）。
- 编辑器 `projectArchive.ts`：保存和选择文件，菜单和启动页都调它。
- 命令行：`tingly-design export <项目> --as zip [--files-only] [--out <文件夹>]` 和 `tingly-design import <file.zip>`（`cli.ts`，见 [cli.md](./cli.md)），直接调同一个 `packProject` / `unpackProject`，不用起服务。项目以路径给出时就地读。
