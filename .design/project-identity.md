# 项目身份：文件夹决定是哪个项目，名字只是显示

状态：**已实施**（接口和地址的现状见 [project-folders.md](./project-folders.md)，命令行见 [cli.md](./cli.md)）。

## 1. 要解决的问题

项目的名字目前同时是三件事：人看到的名字、`?p=` 和 `/api/projects/:p/…` 里的地址、登记表（`.links.json`）和分组（`.groups.json`）的键。这是"所有项目都放在一个全局项目目录里"留下来的：一个目录下的子文件夹天然不重名，所以名字可以当唯一键。

现在项目可以在任何地方（`new` 默认建在当前目录），两个不同位置的项目叫同一个名字是常态。名字不该再要求唯一，更不该因为"全局已有同名"而拒绝创建。身份应该是它所在的文件夹。

## 2. 名字今天被当键的地方

- 地址：编辑器 `?p=`、宿主消息、约 28 个服务端接口的 `:p`、SSE 事件、日志。
- 登记与整理：`.links.json`（名字 → 路径）、`.groups.json`（名字 → 分组）。
- 项目之间的引用：设计系统的安装（`designSystems`）、从别的画布导入的画板（`imports`）记的是别的项目的名字；zip 档案里项目文件夹并排放。
- 运行状态：每个项目一份的 Claude Code 会话、对话记录、`activeDelegates`、文件监听。
- 命令行：`open|check|export|prompt|history` 把名字解析成文件夹。

## 3. 考虑过的办法

| 办法 | 好处 | 问题 |
|---|---|---|
| A. 地址直接用绝对路径（`?p=/Users/me/site`） | 身份和地址一致，不需要登记表里的名字 | URL 带本机路径；上面所有按名字存的东西要改；project-folders.md 当时因此没选 |
| B. 地址用一个由路径生成的稳定短 id，名字纯显示 | 身份是路径，名字可重复，URL 短 | 同样要改所有存名字的地方；短 id 要稳定（文件夹挪走怎么办） |
| C. 保留"短名"当地址，但它只是句柄：由文件夹名生成、撞了加后缀，身份记在登记里（句柄 → 路径），命令行不再把名字当唯一键 | 约 47 个文件里的 `?p=`、接口、引用都不用动；已有项目和链接继续有效 | 句柄 `x-3f9a1c` 仍会出现在地址栏；同名项目靠路径区分，不靠名字 |

## 4. 决定

身份是路径，名字是可以重复的标签，句柄是由路径生成的地址（C 的做法，加上命令行默认按路径）：

- **命令行的项目参数默认是路径**，`export`、`prompt`、`history` 不给就是所在的文件夹（`check`、`list`、`open` 不给另有含义）；按名字找要显式写 `-n` / `--name`。这样 `new` 建在当前目录、后面的命令按同一个路径找，不会因为全局有个同名项目而静默指错。
- **名字对应多个项目时不挑**，列出每个路径，退出码 1。只写一个词、又不是项目文件夹时，报错里告诉人那个名字的项目在哪里，并提示加 `--name`。
- **编辑器启动的 Claude Code 不在项目文件夹里运行**，用环境变量 `DC_PROJECT_ARG=name` 让参数按名字读，skill 里的 `check <name>` 照旧成立。MCP 的项目参数也按名字（`projects` 返回的就是名字）。
- **创建永远不因重名拒绝**（`--global` 要占项目目录里的子文件夹，那是文件系统上的冲突，照旧拒绝）。
- **句柄（`?p=`、接口、登记表、分组）是由路径生成的稳定 id**：项目文件夹里的项目是文件夹名，其余是 `文件夹名-六位路径码`（`site-3f9a1c`）。同一个文件夹总是同一个 id，与登记先后无关；不展示给人，卡片和菜单显示标题。
- **迁移**：登记文件里的旧名字（手起的、按先后加 `-2` 的，撞名的也一样）读进来时保留为别名，仍能解析书签、宿主消息、来源记录；分组按别名换成新 id；第一次启动时登记文件整份改写成新 id 加旧别名。取消登记时连别名一起去掉。

## 5. 没定的

- 项目文件夹里的项目，句柄仍是它的文件夹名（路径的函数，文件系统保证不重名），没有改成不可读的 id。
- 启动页同名卡片并排显示路径（卡片已经写真实路径），`list` 也带路径；文件夹被挪走后只是不出现，没有"找不到，重新指定"。
- 设计系统安装、画板导入记的是出处的句柄；旧名字靠别名继续有效，新写的是新 id。编辑器里"最近打开"记的是旧名字，撞名或登记过的项目会从最近里掉一次。
- 路径变了（文件夹被挪走、改名）就是另一个 id，没有"跟着挪"。
