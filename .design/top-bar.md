# 顶栏：六种类型共用的一条栏

状态：**已实施**。

设计稿在 Tingly Design 自己里：`projects/tingly-design-ui-canvas` 的 "Top bar anatomy"、"Top bar in six kinds" 和 "Menus and dialogs" 三块板（整份自身设计稿见 [self-design.md](./self-design.md)）。改这类界面先在那里画，再改代码。

## 1. 问题

编辑器每种类型自己长了一套"项目外壳"：画布和幻灯片是浮在画面上的小栏，设计系统是侧栏顶部，看板、文档、动效是通栏。同一件事（回首页、项目名、存没存、导入 / 导出、历史）在六个地方长得不一样：有的是图标，有的是文字按钮，有的根本不在；"反馈问题"和"点星"被收进了项目菜单的最后两行，要点开两层才看得到；主题和语言进了编辑器就改不了。

用户的判断：这类入口平时应该在顶栏透出，顶栏可以保留，但要重新设计（不是继续往浮栏和菜单里塞）。

## 2. 决定

一条共用的顶栏 `TopBar`，六种类型都放，位置、顺序、样式一样；类型自己的东西在中间，产品自己的东西在最右。

```
[首页 ▾] 项目名  [历史●]        ……类型的动作……  Import / Export │ [⋯]
```

| 区域 | 内容 | 为什么 |
|---|---|---|
| 左 | 首页和项目切换（`ProjectMenu`）、项目名（双击改名，`ProjectTitle`）、保存状态（`SyncStatus`） | 回答"我在哪、存没存" |
| 中、右 | 各类型自己的动作，顺序固定：模式和视图（动效的尺寸、速度）、这一类的动作（看板的刷新和数据模式、文档的版式）、播放 / 放映（画布、幻灯片）、Import / Export、最后是右侧面板的开关（画布、幻灯片、动效的属性面板由 `TopBar` 的 `panel` 画同一个按钮；看板的来源和代码、文档的评论各有自己的图标） | 各类型的动作不同，但"导入导出"的位置要一样 |
| 最右 | 一个"更多"（⋯）按钮，点开是：反馈问题、在 GitHub 上点星、语言、外观 | 它们属于产品而不属于项目，每种类型一样；但都是低频，四个常驻图标没人知道各是什么，收进一个菜单，栏上的图标少了才认得出每一个 |

| 取舍 | 决定 | 为什么 |
|---|---|---|
| 反馈和点星放哪 | 顶栏最右"更多"菜单的头两行，不再藏在项目菜单第二层 | 原来在项目菜单里，和"去别的项目"混在一起；现在是顶栏上一个固定的位置，一次点击，菜单里有名字有外链标记 |
| 浮栏还要不要 | 画布和幻灯片保留浮在画面上的**工具**栏（选择、文字、形状、页面、缩放）；播放、放映和面板开关上移到顶栏，和其他类型同一个位置 | 工具要贴着画面；项目层面的东西（名称、状态、导入导出）全部上移到顶栏，浮栏里不再有 |
| 常驻图标要不要少 | 少：栏里只留这个类型常用的和"更多" | 图标一多就看不出每个是什么意思 |
| 历史按钮 | 全部类型都是历史图标加状态点（`SyncStatus`），放在项目名旁，不再有"日志""History"文字按钮 | 一个词一个意思（"一个词，一个意思"）；状态点常态下不多一个字 |
| 项目名放哪 | 顶栏，类型各自保留自己的重命名文案和写回方式；画布、幻灯片、设计系统的名字原来分别在属性栏、浮栏、侧栏 | 六种类型的名字在同一个位置 |
| 语言和外观 | 同一个"更多"菜单里，各一组单选 | 原来的缺口：进了编辑器就改不了语言和主题；这两个是编辑器的设置，不是项目的 |
| AI 模型设置 | 仍在项目菜单和请求栏的提示里，不上顶栏 | 低频，且请求栏本来就在说"用哪个模型"；顶栏已经有四个图标 |
| 控件长什么样 | 中间和最右一样，全是灰色图标，只有"开着"的才亮；名字放进悬停提示；只有项目名、字数、尺寸切换和速度这类读数是文字 | 一排彩色文字按钮读起来全是名字，和最右的灰色图标也不是一个风格；图标加提示和"一个词一个意思"一致 |
| 看板的"深色" | 保留在看板自己的动作里 | 这是看板页面的主题，和编辑器外观是两根轴 |

布局：顶栏是固定定位，高度 `--topbar-h`（44px）；每种类型的 `.app` 从它下面开始；请求栏在左侧时，顶栏和整个类型的应用一起在左侧列的右边（外壳给应用一个包含块，顶栏的 `position: fixed` 相对它，不相对窗口）。幻灯片放映时不画顶栏；画布的播放模式里顶栏还在。

## 3. 没选的

- 保留各类型自己的栏、只统一图标和顺序：栏的位置（浮在画面上、侧栏里、通栏）本身就是不一致的来源。
- 做成一个带"更多"的溢出菜单把反馈和点星收进去：又回到"藏在菜单里"。
- 顶栏上放"点星"的文字按钮：每次打开都被提醒一遍，是噪声；图标加悬停说明足够。

## 4. 还没做的

- 窄窗口（小于约 900px）时顶栏中段不折叠，看板和动效的动作多，会挤；需要时把中段收进一个菜单。
