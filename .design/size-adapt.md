# 换尺寸后，内容跟着变

状态：画板、幻灯片、动效都已实施。

## 问题

各类型都能选很多尺寸，但加尺寸、换尺寸之后内容基本不跟着变。原因是同一个：版面是按某一个参考尺寸写死的 CSS 像素（画板根元素自带 `width:1200px;height:760px`），而改尺寸只改了外框或格式表，没人重算版面。

- 画板：W/H 与预设只改 `canvas.json` 里的外框，页面本身被裁掉或留白。
- 幻灯片：尺寸只能在新建时选，之后无法改。
- 动效：新增格式时没有任何 `data-<format>` 覆盖，16:9 的场景原样画进 9:16，固定宽度的行溢出。

## 可选做法

1. 整体缩放（transform）：同比例才对，换比例就是留边或裁切，且改完不能当新尺寸的版面继续编辑。
2. 相对单位、容器查询：写新内容时该用，但救不了已有的 px 内容。
3. 确定性改写源文件：把行内样式里的 px 按轴缩放。结果仍是普通可编辑文件，可撤销，每种类型一样，离线即时。比例变化在约 30% 内效果好。
4. 让 Claude 重新排版：比例大变（16:9 到 9:16）时效果最好，要花一次运行，可能出错；委托通道每种类型都已有。
5. 引入库：没有现成库能把任意行内样式 HTML 改到新尺寸，不值得加依赖。

## 决定

一个共用抽象 `adaptSize`（core 的 `sizeAdapt.ts`）：

- 默认在改尺寸的当下做第 3 种，面板里一个开关“改变尺寸时，内容随之缩放”（默认开，记在浏览器里）。
- 宽高比变化超过 `ADAPT_RATIO_LIMIT`（1.3）时，面板说明“仅缩放可能放不下”，并给“让 Claude 重新排版”（第 4 种），Claude 从已缩放的草稿开始。
- 横向长度（宽、左右、横向内边距）按宽度比，纵向按高度比，字号、圆角、间距、边框、阴影按较小的那个比例，保证文字不会比盒子长得更快。宽高都不超过 64px 的盒子（图标、头像）整体按较小比例，保持形状。
- 只改字面 px；`{{ }}` 孔、`calc()`、`var()`、百分比、`vw` 原样保留。

## 各类型

- 画板（已实施）：预设或 W/H 触发 `resizeBoard`，改页面源文件后再写外框，两步各自可撤销。拖拽外框不触发（那是在裁切）。
- 幻灯片（已实施，基础版）：未选中任何内容时的面板里有尺寸行，改尺寸对每页跑 `adaptSize`（`root: false`，尺寸来自 `deck.json`）再写 `size`。幻灯片不是重点，只保证能放下。
- 尺寸行（W/H、预设、缩放开关、重排提示）是共用组件 `SizeRows`，画板和幻灯片都用它。
- 动效（已实施）：新增格式时 `seedFormat` 用同一遍计算，给每个场景里变了的元素写 `data-<format>` 覆盖，主格式的 `style` 不动；删掉这个格式就连预填一起删掉（`removeFormat` 本来就删这些属性）。已有该格式覆盖的元素跳过。改已有格式的 W/H 不重算（仍是手填）。比例变化大时面板提示并可交给 Claude。

## 未决

- 图片与 `background-size` 目前不特殊处理。
- 模板画板（`<sc-for>`）里循环项的尺寸来自数据时，缩放无法触及。
- 比例大变时是否默认直接让 Claude 重排，而不是只提示，取决于使用中的反馈。
