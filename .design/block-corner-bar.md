# 块角部操作栏：选中的自足块，操作就在它旁边

状态：**已实施（第一期：文档）**。画布、幻灯片、动效的选中元素已有共用右键菜单（[selection-image.md](./selection-image.md)），整页导出见 [export-image.md](./export-image.md)；本篇讲的是另一类东西——文档里那些自己能站住的块——以及所有类型日后共用的那条小栏。

## 1. 问题

文档里有几类"自足"的块：一个 markdown 表格、一段画成表格的 `csv` 围栏、一张 mermaid 图、一条公式。它们每块都是能单独交出去的东西，可是拿不到：

- 原生表格的操作（增删行列、下载 CSV）挤在顶部工具条里，而且只在光标在表格里时才出现；要去够它，眼睛得离开块。
- csv/tsv 围栏画出的表格、mermaid 图、公式**没有任何就地操作**：想拿一张图，只能整页导出再裁。
- 画布的选中元素早就有 Copy / Save as PNG（右键菜单），文档的块连选择模型都没有，这类动作挂不上。

用户此刻想的是"把这个块拿走"：下一步动作应该和块在同一个视野里（UX-First 第 11 条），而不是"记住顶栏里有个入口"。

## 2. 决定

- **入口：`CornerBar`，一个所有类型共用的部件**（`apps/editor/src/components/CornerBar.tsx`）：一张贴着块角的固定定位小药丸，只装图标按钮，动作多于 3 个时收进"⋯"溢出菜单（共用的 `Menu`）。画布画板的悬浮条（`.strip`）是它的先例，但那是画板自己的条；`CornerBar` 是通用的那一个，别的类型日后挂它（画板条要不要换成它，另议，见 §5）。
- **只在使用时出现**：文档没有元素选择模型，块的"选中"就是光标在块里（表格：`isActive('table')`；自绘围栏：`rc-active`）。光标离开，栏就消失——不做 hover 也能出（那会让阅读时到处冒按钮），不做常驻（那是一层常年的噪声，违背"降低视觉噪声"）。
- **最多三个动作，动作来自同一个条目模型**：按钮条目用 `ExportItem` 的字段（id / label / icon / run），和导入/导出菜单、命令行 `offerExports` 同一份词汇；措辞全部复用现成的词条（"Copy as PNG"、"Save as PNG"和右键菜单一字不差，CSV 沿用工具条的"Download this table as CSV"），不发明新词。这个 MVP 里最多三块刚好全放下，溢出菜单是给日后的。
- **只放"拿走"的动作，不放编辑动作**：表格的增删行列留在顶部工具条——角部栏是出口，不是第二工具条。把六七个编辑按钮塞上去，块本身就被盖住了；这是防杂乱的第一条线（见 §3）。
- **画法走现成的路**：PNG 用 `nodeToPng`（画 `rc-view` 或表格元素本身，@2x），保存/复制/失败的提示与所有类型一个样（`saveImage` / `copyImage`）；CSV，原生表格用已有的 `downloadTableCsv`，csv 围栏直接把围栏源文本存成 `.csv`（源就是数据，不必再解析一遍）。
- **位置：贴在块的右上角、悬在块上方 6px，盖不住内容**；上方放不下（视口顶、块在滚动区顶端）就翻到块下方；左右收进视口。定位在 body 上、`position: fixed`，滚动（capture 监听）和窗口变化都跟着走，所以不依赖哪个滚动容器，别的类型拿来就能用。

## 3. 防杂乱的规则（这个功能成败在此）

1. **没有选中就没有栏**。栏是选中状态的 chrome，不是内容的一部分；任何"为了发现性"而常驻或 hover 即出的想法都被否掉——文档是拿来读的。
2. **三个可见动作为上限**。要加第四个，先进溢出菜单；要加第五个，先回答"它为什么属于这块"。
3. **出口动作，不含编辑动作**。编辑动作用户正拿着工具条；把两类混在一栏里，栏就变成了第二个工具条。
4. **词汇不新造**。按钮的措辞、图标、成功/失败提示全部来自现成的共用件（`imageExportItems` 一对、`docs.toolbar.tableCsv`），用户在顶栏菜单见过的词在这里原样出现。
5. **不盖内容、不挤别的浮层**：贴角悬空放置，与气泡菜单、斜杠菜单互不争位（它们绑文字选区，栏绑块）。

## 4. 各类型怎么接

| 类型 | 块 | 状态 |
|---|---|---|
| 文档 | 原生 markdown 表格：CSV / Copy PNG / Save PNG | 已实施 |
| 文档 | csv/tsv 围栏：CSV（源文本）/ Copy PNG / Save PNG | 已实施 |
| 文档 | mermaid 围栏：Copy PNG / Save PNG | 已实施 |
| 文档 | latex 围栏：Copy PNG / Save PNG | 已实施 |
| 文档 | 图片 | 未做（要原创文件的 Copy/Save original，学右键菜单那对；等有人要） |
| 画布/幻灯片/动效 | 选中元素 | 未做——右键菜单已经覆盖，角部栏是叠加不是替换，先不加 |
| 看板 | 部件 | 未做——部件在沙箱框架里，靠"认领"而不是选择模型，得先把选择语义带进框架，另立一篇 |

## 5. 还开着

- 画板的悬浮条（`.strip`）是否收编成 `CornerBar`：形态接近但职责不同（那条常驻、带名字和拖动），先不动。
- 表格要不要"复制为 CSV"（剪贴板 TSV，粘进表格软件）：比"复制为 PNG"更常用的一个出口，等有人要。
- 文档的图片块给原创文件的取用（复用 `saveOriginalImage` / `copyOriginalImage`）。
