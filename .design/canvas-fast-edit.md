# 画布上的快速 AI：排版和跨画板复制

状态：**已实施**（仅画布）。快速 AI 的执行链（jQuery 语句流式执行、写回、撤销）见 [project-kinds.md](./project-kinds.md) 的矩阵；本篇只讲画布上多出来的两件事：它怎么排版，以及怎么把一个部件复制到另一块画板。

## 问题

1. 快速 AI 常把新东西用像素偏移摆（`top`、`left`、`margin` 算出来的值）。人改一句字、换一个尺寸，摆好的块就叠在一起或被切掉。
2. 快速 AI 一次只看见一块画板。"把这张卡片复制到定价那块画板上"只能交给 Claude Code，慢，也用不着。

## 排版

只是提示词，没有机制：`FAST_EDIT_CANVAS`（`packages/core/src/prompt.ts`）的 LAYOUT 一节，只拼在画布的快速 AI 上（`routes/ai.ts` 的 `FAST_PROMPT.design`）。同一段话也写进画布 skill（`.claude/skills/dc-canvas/SKILL.md`）和 Claude Code 的系统提示（`delegate.ts`），三处说同一件事：

- 前后相接的部件放进 flex 或 grid 的父元素，带 `gap` 和 padding，不用像素偏移摆。
- 并排用可换行的 flex 行，一样的卡片用 `auto-fit` 的 grid；装字的盒子不设死高度，宽度来自 flex、`%`、`fr` 或 `max-width`。
- `position:absolute` 只用于放在某个点上的一样东西，和不依赖文字的装饰。
- 画板根元素保留自己的宽高（它们就是画板的尺寸，三处必须一致，见 skill），并且是纵向 flex 容器；空画板或根元素没有任何布局时，第一行先给根元素这些，再一部分一行地填。已经是绝对定位的页面保持它的做法。

没有照搬"根元素 `min-height:100vh`、画板自己长高"：我们的画板尺寸是 `canvas.json` 里的 `w`×`h`，不会自己长高，所以保留固定宽高，只规定它里面怎么排。幻灯片和动效有自己的 CSS 子集（不许 `vh`、`margin`），不拼这一段。

## 跨画板复制

### 选项

| 做法 | 取舍 |
|---|---|
| A. 所有画板都放进沙箱文档，选择器横扫 | 一句 `$('h1')` 会同时改几块画板；要靠事后检查"改了没点名的画板"才能拦住 |
| B. 其他画板留在文档外，只能用 `board(file)` 拿到 | 没点名就碰不到，从结构上排除；要另给其他画板的元素一套不会和当前画板混的句柄 |
| C. 一概交给 Claude Code | 现状，太重 |

选 B。

### 契约

- 当前画板（指着的那块）的句柄还是 `#dc12`，选择器照旧只在它里面找。
- 同一次请求里可改的其他画板（没隐藏、没锁定）按文件名排序，句柄带各自的前缀：第一块是 `#b1_dc3`，第二块 `#b2_dc3`。前缀只是为了让一个句柄在整次回复里只指一个元素；`HANDLE_RE` 认两种，写回时都不进文件。
- `board('Pricing.dc.html')`（文件名，末尾 `.dc.html` 可省）返回那块画板的根元素（不含 `<helmet>` 之类）；`board(f).find('#b1_dc3')` 是它的一个部件。`log(board(f))` 把它的标记（带 `b1_dc…` 句柄）在下一轮给模型看，和现有的 `log()` 一样，一次回复只做这一件事。
- 部件去另一块画板只能是**复制**：`$('#dc9').clone().appendTo(board(f))`；反过来 `board(f).find('#b1_dc3').clone().appendTo('#dc2')`。`.appendTo` 等把别处的元素直接搬过去会被拒（它还连着原画板的源码位置，写不回去），反馈里写明改用 `clone()`。
- 把另一块画板的句柄裸写进选择器（`$('#b1_dc3')`）也被拒，反馈里写出该怎么点名：`board('Pricing.dc.html').find('#b1_dc3')`。这是原版"改了没点名的画板"那条反馈在我们这里的形状：我们的画板不在文档里，横扫本来就碰不到，只剩"裸写句柄"这一种没点名的写法。
- 其他画板的写回和当前画板一样是最小补丁；改了几块就存几个文件，草稿也立即显示在各自的画板上，一次撤销退回整次回复（撤销栈按组，`group`）。存盘冲突时每个文件各自在它的新版本上重放语句，其余画板用请求开始时的版本。

### 没做

- **整块画板的复制或新建**仍然交给 Claude Code：它是一个新文件加 `canvas.json` 里一个位置，不是 jQuery 语句能写的事。提示词里说明了；skill 和委托提示写了怎么复制画板文件。
- **带 `{{洞}}` 或 `<sc-for>` 的部件**复制过去会读目标画板自己的脚本和 `data-props`。提示词要求写成字面文字再复制，依赖脚本的交给 Claude Code。执行器不检查，因为一个新节点看不出它从哪来。
- **隐藏和锁定的画板**不能被改，`board()` 找不到它们，反馈里列出可用的画板。
- 幻灯片和动效没有"另一页"的概念（每页是独立文件，没有同时展示），所以没有 `board()`；它们要改别的页仍交给 Claude Code。

## 还开着的

- 一次请求里要读很多画板的标记时，`log(board(f))` 一块一轮；要不要在请求里直接带上画面里可见的其他画板，看实际用起来的轮数再定。
- 复制带 `{{洞}}` 的部件时能不能由执行器代为带上对应的 `data-props`。
