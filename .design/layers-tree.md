# 图层树

状态：**已实施**（画布、幻灯片、动效）。设计系统、看板、文档没有图层树，原因见 §5。

## 1. 要解决的问题

右侧面板顶部的图层树原来有两份实现：画布一份（`LayerTree.tsx`），幻灯片和动效一份（`SlidePanel.tsx` 的 `Rows`、`SlideLayers`）。两份长得像、行为不一样：词条各一套（`panel.role` 和 `slides.role`，同一个词两处翻译）、展开逻辑不同（画布手动展开加跟随选中，幻灯片根节点固定展开）、动效独有的"何时入场"只在后一份里。想让一棵树多会一件事，就得改两处；想让某个类型的树和别的不一样，也没有一个地方说"这是有意的"。

另一个问题是树只能看和选，不能直接隐藏或锁定一项：要藏一个元素只能去代码里加 `display:none` 或者删掉，要防止误拖只能小心点。

## 2. 决定

**一棵树，一种行。** 行是：展开箭头、角色图标、角色名、“文字前几个字”、（右侧：循环项的个数，或动效里"何时入场"）、隐藏、锁定。画布、幻灯片、动效都用同一个 `LayerRow`，差别只在行从哪里来：

| 来源 | 内容 |
|---|---|
| 画布（`CanvasLayers`） | 画布上的项（便签、标题、形状、图片）、画板，画板展开后是它里面的元素 |
| 幻灯片、动效（`ElementLayers`） | 舞台上那一页或那一个场景的元素；动效额外带一张"不在画面上的元素及其入场时间"的表 |

词条合并到 `panel.role` 一套（多一个 `scene`），`slides.role` 和 `slides.layers` 删掉。

**隐藏和锁定是文件里的内容，不是编辑器的状态。** 理由：这个项目的前提是文件是唯一的真相，人手改、快速 AI、Claude Code 用的是同一份；编辑器里藏起来的东西，Claude Code 看不到，导出也不会跟着藏，重开项目就丢了。所以：

| 对象 | 写在哪 |
|---|---|
| 画板、画布上的项 | `canvas.json` 里该条的 `hidden: true`、`locked: true` |
| 画板、幻灯片、场景里的元素 | 元素自己的布尔属性 `data-hide`、`data-lock` |

属性名不用 `hidden`：幻灯片根上的 `hidden` 已经是"跳过这一页"（放映时不出现），元素上的 `hidden` 又是浏览器自带的含义；`data-hide` 和它们都不撞。

**含义**（改一处，三种类型一致）：

- 隐藏：不画，舞台、播放、导出、动效播放器和渲染都一样。靠一条样式规则 `[data-hide]{display:none!important}`，放在 `SLIDE_BASE_CSS`（幻灯片、场景、放映导出共用）和 runtime 自己的样式里（画布画板）。里面的东西跟着藏，元素还在文件里。画板和画布上的项隐藏时画布上不渲染。
- 锁定：舞台上点不到、拖不动、缩不了、双击改不了字。点到锁定的元素时，选中的是包着它的最近一层没锁的元素（没有就是画板/这一页），不是"什么都没有"，这样点一下不会丢掉原来的选择。锁定的画板连里面的内容一起点不到，仍可从名字条上选中。
- 两者都对里面的所有东西生效：外层藏了或锁了，里层的开关显示为"被外层设置"并禁用，要改去外层。
- 属性面板、图层树本身、Delete 键、撤销不受锁定限制：锁的是"在舞台上手一滑"，不是"这东西改不了"。需要连这些也拦住时再加，现在没有这个场景。
- 幻灯片或场景自己的那一行（根 `<section>`）没有开关：整页隐藏没有意义，"跳过这一页"是缩略图条上另一个开关（`hidden`）。

## 3. 考虑过的其他做法

- **只在编辑器里记（`localStorage` 或 store）**：做起来最快，但前面说了：Claude Code 看不到、不进导出、不跟着项目走。放弃。
- **隐藏写成 `display:none` 样式**：改动了作品本身的样式，取消隐藏时要还原原来的 `display`，原来是 flex 还是 block 没地方记。用独立属性加一条覆盖规则，取消就是删属性。
- **锁定时"穿透"到下面的元素（Figma 的做法）**：画布上元素常常叠着，穿透有用；但这里选的是"选中外层"，因为元素树是嵌套的，外层才是自然的落点，不需要再做一次命中测试。
- **每种类型各一棵、各有各的开关**：这正是要去掉的状态。

## 4. 代码在哪

- `packages/core/src/layers.ts`：`HIDE_ATTR`、`LOCK_ATTR`、`HIDE_CSS`；`Layer.hidden`、`Layer.locked`（元素自己的开关，继承在树里算）。
- `packages/core/src/canvas.ts`：`BoardEntry`、`NoteEntry` 的 `hidden`、`locked`。
- `packages/sandbox/src/runtime.tsx`：`tidOf`（点到锁定的往外找）、`draggable`、双击改字、锁定元素不画缩放手柄。
- `apps/editor/src/components/panel/LayerTree.tsx`：`LayerRow`、`ElementRows`、`CanvasLayers`、`ElementLayers`；动效的 `MotionLayers`（`MotionPanel.tsx`）只算"何时入场"再交给 `ElementLayers`。
- `Canvas.tsx`、`Item.tsx`、`Board.tsx`：画布上的隐藏和锁定。
- 技能 `dc-canvas`、`slides`、`motion` 和 `delegate.ts` 的系统提示都说明了这两个属性：Claude Code 重写元素时保留它们，被要求"藏起来"时加 `data-hide` 而不是删。

## 5. 没有树的类型

设计系统（令牌和组件的列表）、看板（页面是一份代码）、文档（大纲是标题导航，段落不是图层）没有元素树，也不该加：隐藏一个令牌或锁定一个段落没有对应的东西。矩阵里记为 ✗，原因写在行里。

## 6. 还开着的

- 画布上有多页时，树里只列当前页；隐藏的画板在别的页的情况还没有统一的提示。
- 多选后一起隐藏或锁定、按住 Alt 点眼睛只显示这一项（Figma 的做法）：没做。
- 锁定是否也要拦住 Delete 和属性面板：见 §2，等有人遇到再加。
- 导出里隐藏的画板：画布 PNG 导出走画板自己的画面，隐藏的画板不在画布上，也就导不出；这是预期的，没有额外开关。
