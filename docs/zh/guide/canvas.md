# 画布

界面布局：左上是页面菜单和工具条，右上是播放、面板开关、**导入 / 导出**、缩放和同步记录（一个历史图标，角上的点：绿色已保存、蓝色保存中、红色已断开），底部是给 AI 的输入框（可以把图片、PDF、文本文件粘贴、拖入或选择进来，它们会存进项目的 `uploads/`；发出的请求会留在输入框上方，下面是 AI 正在做的每一步、用了多久、改了哪些文件，可以停止、撤销整次改动，失败了可以把请求放回输入框；卡片浮在输入框上方，运行时舞台上的东西不会动；栏头的箭头把它收成一个小药丸，时钟按钮列出之前的请求；一个标记说明 Claude Code 是开新对话还是接着上一次，点一下切换；每种项目都一样），右侧是可收起的面板（`⌘\`）。会写 jQuery 的话，面板的“代码”里、源码下面有一个 jQuery 框，可以自己写语句执行（不需要 API key）；快速 AI 跑完后点“在 jQuery 里改”，会把它写的语句放进这个框，改一改再执行。

- **画布工具**：选择 V、抓手 H、文字 T、画板 A、便签 N、手绘 P、矩形 R、椭圆 O、直线 L、箭头 ⇧L。便签与形状存在 `canvas.json`，有字号（s/m/l/xl/xxl）、颜色、填充、旋转和翻转。
- **导入 / 导出**：同一个菜单。导入收网页和 SVG（变成新画板）、图片（放上画布），也可以拖入或粘贴；导出把选中的画板存成 PNG（1 倍或 2 倍）或源文件，也可以把这一页的每个画板各存成 PNG。
- **画板**：名称条可改名、全屏运行、导出 PNG（1 倍或 2 倍）；右下角拖动改尺寸；多页面（每页一组画板）。
- **右侧面板**：图层树（按角色命名：横向/纵向/网格/文字/图片…，循环项标出来），每一行有“隐藏”和“锁定”：隐藏不删除，锁定后在舞台上点它会选到外面一层，也拖不动；幻灯片和动效是同一棵树、同样的开关（元素上写成 `data-hide` / `data-lock`，画板和画布上的项写成 `canvas.json` 里的 `hidden` / `locked`）；属性页（文字样式、尺寸模式 适应/固定/填充、布局方向与间距、填充、描边、圆角、阴影、不透明度）；代码页（元素自己的声明可直接改，继承来的值只读列出）；微调页（Tweaks，改的是 `data-props` 默认值；声明了 `$time` 的画板会随时间变化，微调页有时间滑块和播放，可以看任意一刻，不改文件。幻灯片和动效可以把这样的画板当特效导入）。
- **直接操作**：选中后拖动可以在兄弟之间重排；拖出父容器变成绝对定位（父元素自动 `position:relative` 并冻结高度）；四角手柄改尺寸；双击就地改字；右键菜单。
- **播放模式**：画板运行自己的逻辑，画板之间的链接可以跳转。
- **导入**：工具条上的导入按钮，或者把文件拖到画布上、粘贴 SVG。网页（连同文件夹）和 SVG 变成新画板，放在当前页已有内容的右边；图片落在松手的位置。原文件留在 `uploads/`。

## 撤销、重做和改动记录

各种类型都一样。

- **撤销 / 重做**（`⌘Z`、`⌘⇧Z`）撤回你自己的上一次改动，再做回来。它按上下文找到你的改动，所以别人（快速 AI、Claude Code、外部编辑）改了同一文件的别处之后仍然能用，他们的改动会保留。历史只存在于这次编辑器会话里（最近 100 步），关掉或切换项目就清空。Claude Code 的一次运行还可以用它结果上的按钮整体撤销。
- **改动记录**（右上角的同步记录）是记录：每次保存到文件的改动一行，写着谁改的（手改、快速 AI、Claude Code、外部编辑、撤销）、什么时候、让 AI 做了什么。一行不是快照，不能回到某一行。
- **提交到 git**（在改动记录里）才是快照：把这个项目的文件夹提交进项目目录的 git 历史，附一句你写的说明，之后可以用 git 回到这一版。撤销不会改动已有的提交，提交也不会清掉撤销。
