# 画布

界面布局：左上是页面菜单和工具条，右上是播放、面板开关、**导入 / 导出**、缩放和同步记录（一个历史图标，角上的点：绿色已保存、蓝色保存中、红色已断开），底部是给 AI 的输入框（可以把图片、PDF、文本文件粘贴、拖入或选择进来，它们会存进项目的 `uploads/`；发出的请求会留在输入框上方，下面是 AI 正在做的每一步、用了多久、改了哪些文件，可以停止、撤销整次改动，失败了可以把请求放回输入框；卡片浮在输入框上方，运行时舞台上的东西不会动；栏头的箭头把它收成一个小药丸，时钟按钮列出之前的请求；栏头的位置按钮把整个输入框搬到左边的一列，这一列一直打开、留着整段对话：每条请求、AI 做的每一步、它的回答和改了哪些文件，刷新后还在，在终端里发的请求也在（窗口太窄放不下这一列时，输入框会自己回到底部）；拖动这一列或任何一个侧栏的边就能调宽窄，双击边恢复原样；一个标记说明 Claude Code 是开新对话还是接着上一次，点一下切换；每种项目都一样），右侧是可收起的面板（`⌘\`）。会写 jQuery 的话，面板的“代码”里、源码下面有一个 jQuery 框，可以自己写语句执行（不需要 API key）；快速 AI 跑完后点“在 jQuery 里改”，会把它写的语句放进这个框，改一改再执行。

- **画布工具**：选择 V、抓手 H、文字 T、画板 A、便签 N、手绘 P、矩形 R、椭圆 O、直线 L、箭头 ⇧L。便签与形状存在 `canvas.json`，有字号（s/m/l/xl/xxl）、颜色、填充、旋转和翻转。
- **导入 / 导出**：同一个菜单。导入收网页和 SVG（变成新画板）、图片（放上画布），也可以拖入或粘贴；导出把选中的画板存成 PNG（1 倍或 2 倍）或源文件，也可以把这一页的每个画板各存成 PNG；“复制为 PNG”把选中的画板放进剪贴板。同一个菜单最后的“整个项目（.zip）”存的是项目本身：所有文件、改动记录，以及装进来的设计系统（并排放着）；“仅项目文件（.zip）”不带这两样。在首页“新建”菜单里选“导入项目包（.zip）…”就能重新打开（重名时加 `-2`），自己把项目文件夹压成的 zip 也行。
- **新建画布**：填完标题后，在十组有名字的尺寸里选第一块画板的大小，每个都写着宽高，下面一行说明用在哪儿：屏幕（画板 1200×760，默认；桌面；手机）、演示（16:9、4:3）、图文与视频（方图、竖图 4:5 和 3:4、快拍 9:16、链接分享卡片、视频封面）、微信（公众号头条封面 900×383、次图 200×200、引导图，视频号封面横版 1080×608、竖版 1080×1260）、国内平台（抖音、微博、B 站）、海外平台（Instagram、X、LinkedIn、Facebook、Pinterest、YouTube）、网页广告（中矩形、通栏、大通栏、半页、摩天楼）和打印（A4、US Letter）；也可以选“自定义”，输入任意宽高（1–7680 像素）。画板面板的“预设”菜单里是同一份列表，[命令行](../cli.md)里 `tingly-design new canvas <名字> --size wechat` 也认。
- **画板**：名称条可改名、全屏运行、导出 PNG（1 倍或 2 倍）；右下角拖动改尺寸；多页面（每页一组画板）。
- **右侧面板**：图层树（按角色命名：横向/纵向/网格/文字/图片…，循环项标出来），每一行有“隐藏”和“锁定”：隐藏不删除，锁定后属性面板、Delete、剪切、排序和包一层都不再动它（面板里有提示和“解锁”按钮）；在树里 Shift 点击或 ⌘/Ctrl 点击选中多行，用树下方的条一起隐藏或锁定；按住 Alt 点眼睛只留这一层显示；锁定后在舞台上点它会选到外面一层，也拖不动；幻灯片和动效是同一棵树、同样的开关（元素上写成 `data-hide` / `data-lock`，画板和画布上的项写成 `canvas.json` 里的 `hidden` / `locked`）；属性页（文字样式、尺寸模式 适应/固定/填充、布局方向与间距、填充、描边、圆角、阴影、不透明度）；代码页（元素自己的声明可直接改，继承来的值只读列出）；微调页（Tweaks，改的是 `data-props` 默认值，所有声明的属性都会列出，没写 `editor` 的按默认值当作文字、开关或数字；文字里显示这样的文字属性时（单独的 `{{heading}}`，或夹在句子里的 `Hello {{name}}!`），双击就是改这个属性或周围的字，模板里的占位保持不变；`<sc-for>` 里循环的列表属性（`"plans":{"default":[…]}`）按行同样原地改；只来自画板脚本数据的文字不再毫无反应，而是说明为什么不能在这里改；样式里整个就是一个占位的颜色（`color:{{accent}}`）在属性面板里显示它真实的颜色，在那里改就是改这个属性；声明了 `$time` 的画板会随时间变化，微调页有时间滑块和播放，可以看任意一刻，不改文件。幻灯片和动效可以把这样的画板当特效导入）。什么都没选时，“画布”下面有一节**模板值**，按画板分组列出整个画布的值，用同样的字段修改（可撤销）；点画板名会选中它并定位到它；超过 30 个值时出现过滤框）。
- **主题**：右侧面板的“主题”页签（选中什么都显示同一份）列出这个画布里已装入的设计系统的每个主题，外加“原样”。点一下，每块画板都换成那个主题；提示条里有“撤销”，卡片下面一行说有几种颜色不属于任何设计系统、保持原样。详见[设计系统](./design-system.md)。
- **直接操作**：选中后拖动可以在兄弟之间重排；拖出父容器变成绝对定位（父元素自动 `position:relative` 并冻结高度）；四角手柄改尺寸；双击就地改字；右键菜单（含“复制为 PNG”：把元素或整块画板的图放进剪贴板）。
- **快速 AI 的排版和复制**：快速 AI 新加的东西用 flex 或 grid 加间距来排，不用像素偏移去摆，改一句字或换个尺寸也不会叠在一起（画板仍保持自己的宽高）。它还能一次请求把一个部件复制到另一块画板上（“把这张卡片复制到定价那块画板”）：是复制不是搬走，两块画板一起保存，一次 ⌘Z 一起撤销。隐藏和锁定的画板不会被改。整块画板的复制或新建交给 Claude Code。带 `{{洞}}` 的部件复制时会把字直接写进去。
- **播放模式**：画板运行自己的逻辑，画板之间的链接可以跳转。
- **导入**：工具条上的导入按钮，或者把文件拖到画布上、粘贴 SVG。网页（连同文件夹）和 SVG 变成新画板，放在当前页已有内容的右边；图片落在松手的位置。原文件留在 `uploads/`。

## 撤销、重做和改动记录

各种类型都一样。

- **撤销 / 重做**（`⌘Z`、`⌘⇧Z`）撤回你自己的上一次改动，再做回来。它按上下文找到你的改动，所以别人（快速 AI、Claude Code、外部编辑）改了同一文件的别处之后仍然能用，他们的改动会保留。历史只存在于这次编辑器会话里（最近 100 步），关掉或切换项目就清空。Claude Code 的一次运行还可以用它结果上的按钮整体撤销。
- **改动记录**（右上角的同步记录）是记录：每次保存到文件的改动一行，写着谁改的（手改、快速 AI、Claude Code、外部编辑、撤销）、什么时候、让 AI 做了什么。一行不是快照，不能回到某一行。
- **提交到 git**（在改动记录里）才是快照：把这个项目的文件夹提交进项目目录的 git 历史，附一句你写的说明，之后可以用 git 回到这一版。撤销不会改动已有的提交，提交也不会清掉撤销。

格式说明：[`.claude/skills/dc-canvas/SKILL.md`](../../../.claude/skills/dc-canvas/SKILL.md)
