# 动效

新建项目时类型选“动效”，然后选尺寸，分类和画布、幻灯片一样（屏幕、演示、图文与视频、微信、国内平台、海外平台、网页广告、打印、更多比例：16:9 给 YouTube 和 PPT，9:16 给抖音和 Reels，还有 1:1、4:5、3:4、4:3 等），或任意宽高。下一个作品默认用上次的尺寸，自己用过的尺寸会和预设放在一起。示例 [`?p=design-motion`](http://localhost:5173/?p=design-motion) 是 36 秒的 Tingly Design 宣传片，同一套场景出 16:9 和 9:16，带独立封面。

![动效编辑器：舞台上是封面，下面是时间轴和场景条，顶栏切换尺寸和速度](../../images/motion.png)

```
projects/<name>/
  motion.json          标题、尺寸 formats、帧率 fps、速度 speed、场景顺序 order、封面 cover
  scenes/<id>.html     每个场景一个文件：正好一个 <section id="<id>">，和幻灯片相同的封闭子集
  renders/             导出的视频（不进 git）
```

- **舞台和播放器**：暂停时，舞台显示播放头所在的场景在这一刻的样子，可以像幻灯片一样直接改。空格播放：播放器接过去，连同转场播完整条时间线；暂停后舞台回来，停在刚才的位置。← / → 逐帧，按住 Shift 每次一秒。舞台下的刻度尺和场景条共用一条时间轴：每个场景块从场景开始的时刻起，到下一个场景接手为止，播放头竖穿两行。在刻度尺上点或拖可以定位，点一个场景就跳到它的开头，双击跳到它的结尾。要改一个场景的时长：拖它的色块右沿（0.1 秒一档，Esc 取消），或在时间轴上方的时长框里直接输入，或在属性面板里改。停在场景开头时，舞台把所有元素按落定的样子画出来，整个场景像一页幻灯片一样可以直接改（时间轴下的标签会写“落定”）；往后走一帧就是真实画面。封面是可选的，放在 0 秒之前，在时间轴最左边单独的一格：点它可以编辑封面（视频缩略图和导出文件的封面图就是它），点“+ 封面”新建一个，点 × 取消封面、改用第一帧。有封面时，打开项目停在封面。封面也可以不是单独一页，而是视频里的某一帧：暂停在想要的那一帧，点时间轴上方的“设为封面”。它会在刻度尺上立一个标记；拖动标记（或选中后按 ← / →）换一帧，打开项目时停在这一帧。它的时间和别的时间一样按阅读节奏写，所以改速度时它跟着场景一起走。
- **手动管理场景**：时间轴上方的“+ 场景”在播放头所在场景之后新建一个场景（样式照邻居），并跳到它。右键场景块可以在后面新建、复制、前移、后移或删除（最后一个场景删不掉）。顺序就是 `motion.json` 的 `order`。
- **批注**：顶栏的"批注"展开两个框：整个作品的批注（`motion.json` 的 `note`）和舞台上这个场景的批注（场景文件末尾的 `<aside>`，和幻灯片的演讲者备注是同一种写法）。写给谁看、什么调子、这个场景要讲什么；批注不会画进画面，也不会渲染，你向 Claude 提要求时它会读到。有批注的场景块上有一个小点。
- **在舞台上改**：单击选中，双击改字，拖手柄改尺寸（Shift 保持比例，Alt 从中心缩放，边缘会吸附到其他元素）。右侧面板：选中元素时是它的样式；选中场景时是场景时长、转场和背景；什么都没选时是作品的尺寸。播放头这一刻不在画面上的元素点不到，可以从图层里选，图层会标出它们何时入场，每行同样有隐藏和锁定（隐藏的元素播放器和渲染里也不出现）。选中的元素显示它落定的位置，而不是入场到一半。撤销和其他类型一样。
- **尺寸**：`motion.json` 里的每种尺寸都用同一套场景播放，在顶栏切换，在面板里添加（和新建时同一个尺寸选择器）、改尺寸或删除。看着第一种尺寸时的改动对所有尺寸生效；在别的尺寸里改，会写成这个尺寸的覆盖（`data-tall="…"`），面板会写明改到哪里。点覆盖标签可以退回共用的值。
- **导入图片**：把图片或 SVG 拖进来、粘贴，或用顶栏的导入按钮，放到播放头所在的场景上，从播放头这一刻淡入（停在场景开头时从 0 开始），原文件存进 `uploads/`。
- **内置特效**：一个空的 embed 加上 `data-fx`（`<x-embed data-fx="aurora" data-seek …>`）就画出十六种 WebGL 特效之一：背景（`flow`、`aurora`、`mesh`、`plasma`、`waves`、`grid`、`stars`、`halftone`）和叠加层（围着卡片流动的 `edge-glow`、扫过标题的 `sweep`、`rays`、`ripple`、`particles`、`light-leak`、`scanlines`、`grain`），参数写在名字后面（`colors: #3d7bff #9861ff; speed: 0.5`）。`scale`、`direction`、`at`、`region` 可以改变形态：`aurora; region: 0% 55% 100% 45%` 就是只铺在画面下方的极光。编辑器、播放器和渲染出的视频是同一帧。浏览器无法启动 WebGL2 时会画一个简化的 CSS 版本，编辑器会说明；名字或参数写错时 `tingly-design check` 会报出来。
- **从项目导入**："导入 / 导出"菜单里的"从项目导入…"列出各个画布的画板。选中的画板复制进这个动效（`uploads/<画布>-<画板>/`），放到播放头所在的场景。会随时间变化的画板（特效）铺满画面、放在最底层，按场景时间逐帧绘制，舞台、播放器和渲染出的视频都一样；静止的画板从播放头淡入。选中它可以改参数、打开原画板，或从原画板更新。
- **速度**：时间按阅读节奏来写，`motion.json` 的 `speed` 决定视频播多快。速度菜单可以试别的节奏，不改任何文件。
- **检查**：列出时间上的问题，比如退场早于入场、文字停留不到 0.8 秒、导不出的嵌入。
- **AI**：底部输入框针对播放头所在的场景，或选中的元素。小改动选快速 AI，马上落在舞台上；大改动选 Claude Code，它会知道你看的是哪个场景、哪一刻、哪种尺寸。
- **保存当前帧**：“保存当前帧为图片”把播放头所在的画面按当前尺寸存成 PNG。
- **导出**：“导入 / 导出” → “视频…”打开一个对话框，只有一行摘要（“MP4 · 1920×1080 · 30 帧/秒 · 整段”）和“导出”按钮，多数时候点一下就够了。“更多选项”展开后可选格式（MP4，浏览器写不了 H.264 时用 WebM；WebM；GIF）、尺寸（作品自己的，或更小的常见高度）、帧率、质量、范围（整段，或只导出播放头所在的场景，场景里的那一段声音会带上）。上一次视频的格式、尺寸、帧率和质量下次作为起点（GIF 不改变它们）。每个视频文件都带一条音轨，没有声音的作品写一条静音轨，因为有的平台拒收没有音轨的文件。GIF 也可以直接点菜单里的“GIF…”，默认小尺寸、15 帧/秒。视频在这个标签页里生成，不用装任何东西：浏览器能写 H.264 和 AAC 时（Chrome、Edge、Safari）存 MP4，否则存 WebM，提示会说是哪种、为什么。完成前请让标签页留在前台；栏里会出现进度和取消按钮。字体和音频文件会一起带上。含嵌入内容（`<x-embed>`）或视频层的作品改由运行服务端那台机器上的 Chrome 或 Edge 来画（还需要 ffmpeg），对话框里会说明；这条路线同样可选尺寸、帧率、范围，格式只有 MP4 和 GIF（没有 WebM）。机器上两样都没有时，视频仍在这个标签页里生成：每个嵌入内容逐帧交出自己的画面（稍慢一些）；没交出画面的场景会在提示里点名，视频层在这条路线上不逐帧对齐。文件会把封面存成封面图片，文件管理器和播放器用它当缩略图（MP4 和 WebM，和命令行一样）。对话框的“更多选项”里还有一个勾选项，可以同时把封面放在视频第一帧，给只显示第一帧的软件用；默认不勾，除非 `motion.json` 里写了 `"coverFirstFrame": true`；同一个菜单里的“封面图片”把封面存成 PNG（按当前显示的尺寸；没有封面时是第一帧）；“PNG 图片”存播放头所在的那一帧，“复制为 PNG”把它放进剪贴板。用[命令行](../cli.md)：`tingly-design export <name> --as mp4 [--format wide]` 为每种格式写一个 MP4（带封面图），封面 PNG 写在旁边，都放进 `renders/`；`--as gif`、`--as png`（只要封面）同理。用的也是本机的 Chrome 或 Edge 和 ffmpeg。`--as html` 写一个谁都能打开的单文件 HTML 播放器（所有格式、进度条、速度），什么都不用装；`--scale 2` 每帧按两倍大小画再缩回来，文字更清晰。同一个菜单最后的“整个项目（.zip）”存的是项目本身：所有文件和改动记录；“仅项目文件（.zip）”不带改动记录。在首页“新建”菜单里选“导入项目包（.zip）…”就能重新打开（重名时加 `-2`），自己把项目文件夹压成的 zip 也行。

时间写在元素上：`<section>` 上的 `data-duration`、`data-transition`，以及里面任意元素的 `data-in` / `data-out` 预设（`rise`、`drop`、`type`、`count`…）和 `data-keys` 关键帧。
