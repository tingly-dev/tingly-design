# 幻灯片

新建项目时类型选“幻灯片”。示例 [`?p=tingly-intro`](http://localhost:5173/?p=tingly-intro) 是“Meet Tingly”，介绍 Tingly Box 和 Tingly Design；网关一页右侧是一段 `<x-embed>` 实时动画图。

新建时可在标题下面选尺寸：和画布、动效一样的分类、具体宽高与自定义输入。默认 1920×1080，也可选竖版、方形和更多比例，编辑、放映和导出都使用所选尺寸。尺寸存入 `deck.json` 的 `size: [宽, 高]`；旧项目仍用默认尺寸。

![幻灯片编辑器：左侧缩略图与分节，中间舞台和演讲者备注，右侧图层与属性](../../images/slides.png)

```
projects/<name>/
  deck.json            标题、顺序 order、分节 sections、字体 faces
  slides/<id>.html     每页一个文件：正好一个 <section id="<id>">，所选尺寸（默认 1920×1080），封闭的 HTML/CSS 子集
  assets/              上传的图片和字体
```

- **左侧缩略图条**：按节分组（双击节名改说明）；拖动排序；右键新建、复制、跳过、从这一页开始新的一节、删除。缩略图里的动态嵌入不运行，只显示占位。
- **舞台**：当前页按比例缩放；选中、双击改字、拖动重排或拖出成自由定位、右侧面板（图层/属性/代码，图层同样每行可隐藏、可锁定）和画布完全一样，走同一个最小补丁回写。下方是演讲者备注（写进 `<aside>`）。
- **文本框**：装着段落和列表的 `<div data-text>` 是一个框：单击选中整个框（一起移动、改尺寸、设样式），双击在指针下的那一段里打字，`data-text="N"` 设列表缩进（px）。
- **插入**：文字、图片（上传到 `assets/`）、表格、形状（矩形、圆角、椭圆、菱形、四向箭头、直线）、连线、图标。
- **格式检查**：每一页都按原版 `format.md` 的子集检查（不认识的标签、`margin`、`z-index`、`em`、`var()`、`<x-embed>` 没有钉住……），舞台上方和缩略图上标出处数，点一条就选中对应元素。快速 AI 改完如果引入了新的越界，会被撤销并把原因告诉模型重写。
- **放映**：F5 从头、⇧F5 从当前页；→ / 空格 / 点击 先播放这一页的出场动画（`data-build-in`），再翻页；切换效果 `fade` / `push`（`magic` 先按淡入淡出处理）；N 打开演讲者备注栏；F 全屏；Esc 退出。
- **导入 / 导出**（右上角，“放映”旁边）：一键存成 PDF，每页幻灯片占一页（由运行服务端那台机器上的 Chrome 生成；没有 Chrome 时打开打印窗口，自己选“另存为 PDF”）、单个 HTML 文件（图片内联、嵌入在沙箱里照常运行、方向键翻页）、Markdown 文件（把幻灯片写成一篇文档：标题、分节和每页标题成为小标题，文字、列表、表格照原样，图片保留路径和说明，演讲者备注成为引用；形状和嵌入块不进文件）、演讲者备注文本。同一个菜单还能把当前这页或每一页存成按页面尺寸的 PNG 图片（嵌入内容在图片里是空的），把当前这页作为图片复制到剪贴板（“复制为 PNG”），也可以导入图片和 SVG。同一个菜单最后的“整个项目（.zip）”存的是项目本身：所有文件、改动记录，以及装进来的设计系统（并排放着）；“仅项目文件（.zip）”不带这两样。在首页“新建”菜单里选“导入项目包（.zip）…”就能重新打开（重名时加 `-2`），自己把项目文件夹压成的 zip 也行。
- **导入图片**：把图片或 SVG 拖到编辑器里或直接粘贴，放到当前这张幻灯片上（和"插入图片"一样存进 `uploads/`）。
- **内置特效**：一个空的 embed 加上 `data-fx`（`<x-embed data-fx="aurora" …>`）会画出会动的 WebGL 背景或光效，和动效里的十六种相同（见动效指南）。编辑时和 PDF 里是静止的一帧，演示时和下载的 HTML 里会动。
- **从项目导入**："导入 / 导出"菜单里的"从项目导入…"列出各个画布的画板。选中的画板复制进这份幻灯片（`uploads/<画布>-<画板>/`），放到当前这一页。会随时间变化的画板（特效，标着"会动"）铺满整页、放在最底层，放映和下载的 HTML 里循环播放；静止的画板放在中间。选中它可以改参数（写在嵌入块上，副本保持原样）、打开原画板，或从原画板更新：用到它的每一页一起变。

渲染上忠实于原版的几处规则：没写 `display` 的 `<div>` 是纵向 flex；子元素按源码顺序绘制，所有流式内容作为一层画在第一个流式子元素的位置（所以写在最前面的全幅背景会在文字下面）；`<x-embed>` 跑在独立的沙箱页里（无网络、不同源）。

## PowerPoint（.pptx）

在首页选择 **新建项目 → 导入 PowerPoint（.pptx）…**，或将 PPTX 拖到启动页。它会变成一个**新的幻灯片项目**，不是附件，也不会追加到已打开的牌组。命令行使用同一个转换器：`tingly-design import talk.pptx`。重名时自动选择空闲后缀。转换摘要把每种变化只说一次，并列出它涉及的页和对象；原始 PPTX、图片和 JSON 报告保留在 `uploads/` 下。转换失败不创建项目。

导入遇到读不了的内容会继续：转换不了的对象略过，并注明在哪一页，其余内容照常导入。文字及其样式（混合字号与字体、间距、自动缩放）、项目符号与编号、占位符和主题继承、预设与自定义形状、直线与连接线、实色/渐变/图案/图片填充、阴影、分组、裁剪图片、含合并单元格与表格样式的表格（PowerPoint 的全部内置样式，文件只写样式名时也能还原，含行列条带、首末行列、双线与对角线边框、竖排文字）、SmartArt、背景和演讲者备注都转为可编辑内容。图表按自身数据重绘成与原图一致的图片：柱形与条形（含 3D，画出简单的立体感）、折线、股价、面积、散点、气泡、饼图、圆环、复合饼与复合条饼、雷达、曲面（画成等值线图）、双坐标轴组合图、对数与日期坐标轴、数字格式、数据标签、趋势线和误差线，以及 Office 2016 新图表（瀑布、漏斗、直方图与帕累托、箱线图、树状图、旭日图）；地图图表显示文件里保存的图片；要改数字，请在原文件里改图表。牌组保留演示文稿的页形：4:3 仍是 4:3，竖版仍是竖版。动画会去掉并说明。只有损坏、不安全（宏或 ActiveX）或超出大小限制的演示文稿会整份拒绝。旧 `.ppt` 和加密演示文稿不支持。

把 PPTX 拖进已打开的幻灯片项目，它的页会作为普通幻灯片追加到牌组末尾——一次撤销即可移除整批，转换报告保留在 `uploads/` 下。

在幻灯片项目的 **导入 / 导出** 菜单选择 **PowerPoint（.pptx）**，保存整份可见牌组。文字、支持的形状和图片生成原生 PowerPoint 对象；演讲者备注仍是备注。隐藏页和隐藏元素不输出。编辑仍发生在普通幻灯片文件中；导出重新生成一份包，不更新原始 PPTX。

导出测量真实页面布局，尽量保持可编辑：文字（含字距、大写变换、删除线和透明度）、实色或半透明填充与圆角的方框、边框（只有一边的边框变成线条）、列表符号、PNG/JPEG 图片，以及表格：单元格里只有文字的表格会成为真正的 PowerPoint 表格，保留合并单元格、填充、边框、内边距和对齐，在 PowerPoint 里可以继续改样式、加行（单元格里有图片、图标或旋转文字，或单元格之间留了间距的表格，则逐个单元格导出）。PowerPoint 没有对应对象的内容（渐变、阴影、SVG 和图标、嵌入块、旋转或裁剪的元素、其它图片格式）只把这个元素作为图片放在它原来的叠放位置；渐变卡片上的文字仍是文字。结果会按页列出每个变成图片的元素。不承诺字体显示完全一致或保留原段落的完整重排语义，也不嵌入字体。只有内容根本无法读取时（图片缺失、字体未加载、超时）才失败，失败不下载残缺文件。`tingly-design export talk --as pptx --out ./exports` 将文件写入 `exports` 目录，MCP export 使用同一链路。它也接受可见页的范围：`--slide 2`、`--slide 2-4` 或 `--slide 1,3-4`（位置从 1 起按可见牌组数，范围不指名隐藏页）。范围导出的文件名会带上范围。

格式说明：[`.claude/skills/slides/SKILL.md`](../../../.claude/skills/slides/SKILL.md)
