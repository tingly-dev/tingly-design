## Files of a system (paraphrased)

All under `project/`:

| path | what |
|---|---|
| `design-system.json` | index: `{"v":3,"layout":"files","createdOnFiles":{…},"title","namespace","libraries":[{name,version}],"sections":{},"groups":[…],"assetGroups":{<Group>:{name,tile:"l"…"xs",order,files:{<name>:{name,blob,size,type}}}},"blobs":{},"docs":{"readme":"project/README.md","sections":[]},"lastChange":{by,at,via,note}}`; written LAST |
| `tokens.json` | `{name,version,color:{themes:[{id,name}],tokens:[{name,value:{<theme>:…},usage}]},type:{fonts:[{family,file,weight}],families:{…},groups:[{name,family,styles:[{name,fontSize,lineHeight,fontWeight}]}]},spacing:{tokens:[…]},radius:{tokens:[…]},shadow?…}`: every family is a LIST of `{name,value,usage}` (not DTCG maps); color aliases `"{other}"` |
| `README.md`, other `*.md` | the brand book (≤24 sections) |
| `components/<Comp>/README.md` | guidelines (first sentence = summary) |
| `components/<Comp>/preview.html` | live preview; line 1 `<!-- @dsCard group="Actions" height=88 -->`; runs with tokens.css, fonts, bundle.css, libraries and the bundle preloaded |
| `components/bundle.js`, `bundle.css`, `index.d.ts`, `lib/*.js` | one classic script assigning `window.<namespace>` |
| `components/Cover/preview.html` | the cover above the brand book |
| `assets/<Group>/<file>` | uploads named by the index's `assetGroups` |
| `fonts/<file>` | listed by `tokens.json` `type.fonts[].file` |
| `api/…`, `tokens.css`, `manifest.json` | generated by the page; never written |

## How other types consume it

- Design and Slides record installed systems in their index's
  `designSystems: [{title, namespace, artifact, version, copiedAt}]` and copy
  the files they use to `project/ds/<folder>/…` (tokens.json, fonts, pictures).
- With `tokens.json` installed, the Theme menu, color pickers and Text style
  menus offer the system's tokens instead of bare hexes.

## What it means for tingly-design

A design system is just another file-backed project kind. The useful part to
replicate first is the consumer side: read `project/ds/<folder>/tokens.json`
and offer its colors / text styles in the right panel (Design and Slides
alike).
