Tingly Design Docs文档 GitHub

People and AI edit the same design files.

人和 AI，改的是同一份设计文件。

Tingly Design is an open-source design tool. Canvases, slides, design systems, dashboards, docs and motion pieces are plain files; click and drag on screen, let a fast model rewrite a line, or hand a whole task to Claude Code. Every edit writes back only the characters that changed.

Tingly Design 是开源的设计工具。画布、幻灯片、设计系统、仪表盘、文档和动效都是普通文件：在屏幕上点选拖拽，让快速模型改一行，或者把整个任务交给 Claude Code。每次编辑只写回变了的那几个字符。
