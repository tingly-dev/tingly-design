Edit it both ways.

人机协同设计，

Drag on the canvas, or let a model and Claude Code change the file: whichever side you edit, the other updates at once. Canvases, slides, design systems, dashboards, docs and motion are all plain files, and every edit writes back only the characters that changed.

在画布上点选拖拽，或者让 AI 和 Claude Code 直接改文件：改哪一边，另一边立刻同步。画布、幻灯片、设计系统、仪表盘、文档、动效，都是普通文件，每次编辑只写回真正变了的那几个字符。

Beyond the editor: CLI, skill, MCP

编辑器之外：CLI、skill、MCP

Needs Node 20 or newer. Edits made this way show up live in the editor you have open, credited to whoever made them.

需要 Node 20 或更新版本。这样做出的改动，会实时出现在你已打开的编辑器里，并记在改动者名下。

CLI

Create a project, open it in the editor, ask Claude Code to change it.

新建项目，在编辑器里打开，让 Claude Code 来改。

npx tingly-design new slides pitch
npx tingly-design open pitch
npx tingly-design prompt pitch \
  "Tighten the title slide"

open starts the editor and stays up; run prompt in a second terminal.

open 启动编辑器并保持运行，在另一个终端里运行 prompt。

Skill

Teach Claude Code the file formats, then talk to it in your folder.

让 Claude Code 认得文件格式，然后在你的文件夹里直接对话。

cd my-work
npx tingly-design skills add
npx tingly-design new slides ./pitch
claude

Ask “Make a Q3 pitch deck in ./pitch”; watch it with npx tingly-design open ./pitch.

对它说“做一份 Q3 汇报幻灯片，放在 ./pitch”；用 npx tingly-design open ./pitch 看过程。

MCP

Give any MCP-capable agent the same commands as tools.

让任何支持 MCP 的 agent 以工具的方式用同样的命令。

claude mcp add tingly-design \
  -- npx -y tingly-design mcp

Keep npx tingly-design running to watch its edits live.

保持运行 npx tingly-design，就能实时看到它的改动。
