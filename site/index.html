Open-source design tool

开源设计工具

Co-design with AI.
Edit it both ways.

人机协同设计，
双向编辑。

Drag on the canvas, or let a model and Claude Code change the file: whichever side you edit, the other updates at once. Canvases, slides, design systems, dashboards, docs and motion are all plain files, and every edit writes back only the characters that changed.

在画布上点选拖拽，或者让 AI 和 Claude Code 直接改文件：改哪一边，另一边立刻同步。画布、幻灯片、设计系统、仪表盘、文档、动效，都是普通文件，每次编辑只写回真正变了的那几个字符。

Fast AI, Claude Code, you

快速 AI、Claude Code、你自己

Rewrite a line in seconds, or whole files in minutes, or edit by hand. The editor follows live.

几秒改一行，几分钟改整份文件，或者自己手改。编辑器实时跟上。

Every change, from any side, lands in one journal: who changed what and when, with undo. 无论谁改的，每次改动都记进同一份记录：谁、改了什么、什么时候，都能撤销。
